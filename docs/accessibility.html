Accessibility

Peg Game Idle targets WCAG 2.1 AA on core flows: play the board, buy upgrades, complete the daily puzzle, and manage settings.

Supported features

VoiceOver

  • Each board hole is a button with state-specific labels (peg, empty, selected, landing target).
  • Tab bar, currency header, upgrade rows, and settings toggles expose accessibility identifiers.
  • Toasts post accessibility announcements when they appear.

Tap and drag input

Jump pegs by dragging peg → landing hole, or by two-step tap (select peg, tap hole). Both paths use the same rules.

Dynamic Type

Primary UI uses system text styles. Stats and upgrade rows use ViewThatFits layouts to adapt at larger text sizes.

Reduced Motion

When iOS Reduce Motion is on, the app disables or shortens:

  • Launch splash crossfade
  • Ambient background particles
  • Peg jump arcs and deal animations
  • Toast slide transitions and prestige celebration effects

You can also turn off ambient particles in Settings → Feedback → Ambient motion.

Color and themes

Four color themes (Slate, Forest, Ocean, Sunset) adjust accent and surface colors. Landing holes use a distinct glyph, not color alone, to indicate valid targets.

Touch targets

Interactive controls aim for at least 44×44 pt minimum touch targets.

Known limitations

  • Some compact stat labels may truncate at the largest Dynamic Type sizes; the stacked layout is used when horizontal space is tight.
  • Locked achievements show as "???" until unlocked — by design for discovery.
